Stock Sheet v1

The one PDF layout the system reads. Every stock sheet is built exactly this way — same columns, same order, same number formats — so that an import either goes through cleanly or says precisely what is wrong.

One format · no variations

01The template

A4 landscape, one page, one table. Built in Excel and saved straight to PDF. Below is the sheet exactly as it must print — this example carries five grades and five sieve sizes; a real sheet carries as many rows and size pairs as the office needs, in this same shape.

Three parts, in this order and no other: the grade rows, one unnamed subtotal row, one TOTAL row. The subtotal row's grade cell is left empty — that is how the system tells a subtotal from a holding. 02The rules

Page & export

  1. R1Save to PDF from Excel — File → Save as → PDF. Never scan or photograph a printout: a scan holds a picture, not text, and no import can read it.
  2. R2A4 landscape, one page, one table. If the rows do not fit, reduce the font — never continue onto a second page and never place a second table below the first.
  3. R3Calibri or Arial, 8pt or larger. No merged cells inside the grid, no wrapped text, no rotated headings.

Columns

  1. R4Column A is the grade name, at least 25 mm wide, left-aligned. Nothing else goes in it and no grade name may spill into the column beside it.
  2. R5Then one pair of columns per sieve size: carats, then rate. In that order, every time. No serial-number column, no remarks column, no row-total column at the right.
  3. R6Every number is centre-aligned in its cell. Right-aligned figures shift as digits are added and can be read into the wrong column.

Heading & date

  1. R7Two lines above the table, centred: STOCK SHEET, then DATE: DD-MM-YYYY — DATE: 09-08-2026. The date is for the person checking the sheet; the operator keys it in at import.
  2. R8The heading row reads GRADE, then each size label centred over its carat column, with RATE over each rate column. It must carry no number other than the size labels — no year, no column count, no page number.

Grade rows

  1. R9Every row carries a grade name. No blank grade cells, no spacer rows, no sub-headings inside the table. A row left blank still imports — its carats and rate land under a grade called Unknown Grade — but then somebody has to work out afterwards where they belong.
  2. R10Use the approved names in §3, spelled exactly. Ten characters or fewer, and never the word TOTAL inside a grade name.
  3. R11Carats: two decimals, always filled. 4.87, 16.36, 0.00 for an empty bucket. No blanks, no negatives, no ct, no dashes.
  4. R12Rate: whole rupees per carat. 58000 or 58,000. No ₹, no /ct, no decimals. Put 0 where a bucket is not priced.

Subtotal & total

  1. R13One subtotal row, directly under the last grade row, with its grade cell empty. Do not write the word SUBTOTAL. Fill every column: each size's carat subtotal and each size's rate.
  2. R14One TOTAL row, directly under the subtotal. TOTAL in column A, total carats next, average rate after that. Exactly one TOTAL on the sheet.
  3. R15The arithmetic must be right. Each subtotal is the exact sum of its column; total carats is the sum of the subtotals. These figures are the system's proof it read the sheet correctly — it refuses on a difference of 0.005 ct.

04What stops an import

A stock import replaces the position, so a sheet that reads 95% correctly would quietly become the official figure. Each of these refuses the whole file and nothing is written — the message names the figure the sheet states and the figure the system found.

01

The file is a scan

A photograph or scan of a printout holds no text. Export from Excel instead.

02

The totals do not agree

A subtotal or the grand total differs from what the rows add up to. Fix the sheet's own arithmetic and export again.

03

No heading row naming the sizes

Usually the wrong file: an invoice, a receipt or a sales report rather than the stock sheet.

04

A size or grade the system does not hold

Not fatal — the app offers to add it, named exactly as the sheet prints it, then reads the sheet again.

05Before sending a sheet

  • Saved as PDF from Excel, not scanned
  • One page, one table, A4 landscape
  • Every row has a grade name; every carat cell has a figure
  • All numbers centred; carats to two decimals; rates whole
  • Subtotal row present, its grade cell empty, every column filled
  • TOTAL row present and the arithmetic checked

If a sheet is refused, the message names both figures — the one the sheet prints and the one the system read. That difference is almost always the fastest way to the answer.
